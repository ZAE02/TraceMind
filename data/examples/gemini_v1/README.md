# Gemini 开发集示例

这里发布三场已完成并通过模型内容审查的虚构成人咨询会话，仅来自开发组，不包含测试组设定或评审映射。

请求模型为 `gemini-3.8-flash`，返回模型字段为用户批准的 `gemini-3.8-flash-tiered`。每条发言单独生成，实际输入采用有记录的有限历史选择策略。场景种子保留其原有 Terra 作者及模型审查来源，没有复用 Terra 对话。

质量审查使用同一模型的独立无状态请求；发布前核对了会话内容哈希及审查来源任务。`review_source_job_id` 和各条发言的来源哈希用于追溯，不包含 API 凭据。模型审查不代表人工或临床认可，三场示例也不代表完整 Benchmark 已完成。
