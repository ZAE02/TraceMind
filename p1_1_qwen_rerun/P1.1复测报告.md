# P1.1 复测报告：Qwen Flash 作答，Qwen Max 评分

生成日期：2026-10-14（Asia/Shanghai）。**状态：全量运行及自动审计完成；尚未人工评审。**

## 设计与可比范围

沿用原 P0 的 8 个拟真合成案例、64 次会话、24 个检查点与 C0–C3 输入；232 个非答卷输入文件与原 P0 逐一哈希相同。原案例本身由 DeepSeek Pro 合成，本次没有重写案例。新生成的 192 份 Task A/B 答卷、C4/C5 理解记录和咨询回应均使用 `qwen3.7-flash-2026-07-15`；24 份参考标注复核以及所有盲评均使用 `qwen3.8-max`。检索输入沿用已固定的 Qwen Embedding Flash 结果。

因此，与旧 P1 比较时，**答题模型与评审模型同时改变**，分数变化无法单独归因于评审模型。两者均属 Qwen 系列；盲化条件编号能减少条件名称偏差，但不能证明评分者准确，也不能排除同系列偏好。下列结果只是对这批合成材料的模型评审。

## 持续维护与按需重建

关键对照是 **C5 与 C4-full**：两者生成回应时都能访问相同的完整公开历史，C4-full 在检查点从全部已完成会话重新整理四字段理解，C5 在每次会话结束后滚动更新。

| C5 − C4-full，0–4 分 | 均值差 | 95% 案例聚类区间 |
| --- | ---: | ---: |
| A 证据支持 | −0.33 | [−0.50, −0.17] |
| A 进展理解 | −0.29 | [−0.54, −0.04] |
| B 历史利用 | +0.25 | [0.00, 0.50] |
| B 探索价值 | +0.21 | [−0.17, 0.54] |
| B 回应恰当性 | +0.04 | [−0.25, 0.33] |

C5 在探索价值与回应恰当性上均未显示稳健优势；理解记录的证据支持与进展理解反而较低。检索版 C4 与 C5 的历史访问不等，不能替代 C4-full 作为机制结论。C5 相比 C5-minus 的探索价值差为 `+0.25 [-0.04, 0.46]`；6 节点直接回应探测差为 `+0.50 [0.17, 0.83]`，但节点数少，不能证明完整机制效应。

同一份 C5 回应在机制盲评与 C4-full 对照盲评中分别得到 2.75 与 2.58 的探索价值均分；24 个节点中有 4 个节点评分不同（最大相差 1 分）。这体现评审上下文或重复调用的敏感性，解读约 0.2 分的机制差异时必须谨慎。

C5 的记录更新加回应共 **72 次**成功生成，约 28.8 万输入 / 5.2 万输出 token；C4-full 为 **48 次**，约 30.3 万输入 / 2.1 万输出 token。C5 额外调用与输出成本更高。以上只计最终保存的成功机制生成，不含所有重试；全量 API 用量见 `verification.json`。

## 结论边界

这次复测缓解了旧评审几乎全部满分的问题，但仍**不能证明持续维护优于按需从完整历史重建**。错误标记在复评中存在分歧，参考标注也只有模型复核。正式研究前，应让独立受训评审者对分层抽样答卷和争议错误做盲评，并预先规定缺失型错误如何引用证据。全部原始答卷、评分、无效输出和匿名映射已留存，便于逐条复查。
