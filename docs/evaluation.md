# 评测、标注与结果边界

正式实验使用 `v2` 数据。当前真实规模由 [status.json](status.json) 给出；目录数量不代表完整轨迹数量。评测任务均通过持久化队列执行，未完成任务不会生成候选答卷或评分结果。

## 条件与上下文

五个正式方法为当前会话、时序 RAG、滚动摘要、按需重建和演化记忆；Oracle Evidence 单独用于诊断。历史证据与记忆共同遵守 4,096 个 BGE-M3 tokenizer token 的上限，当前输入和固定指令另计。时序 RAG 在重排结果中增加最早及最近历史阶段的覆盖；向量索引必须完整覆盖该冻结点的历史 ID，否则停止执行，避免把索引缺失误当成方法效果。

每次模型任务保留输入、实际结果、哈希及来源。实验候选、标注、质量评审和访问归因分别使用新的隔离任务；生成对话的角色不能继续承担这些任务。任务来源是调度记录和报告身份，不能视为平台提供的加密证明。

## 参考标注与评分冻结

参考标注只接收冻结前的公开历史，每条认识绑定发言 ID；Oracle 列表只能引用既往会话，当前片段单独提供。标注包含已获认识、修订关系、未解问题、可接受探索及应避免的预设，不包含唯一标准咨询台词。

草稿经独立任务审查。拒绝后保存不可变的草稿与审查记录，将具体意见交给新的草稿任务，最多三次；仍被拒绝则显式停止，等待检查。通过的标注仍标为 `model_reviewed_not_human_gold`。重读时核对原始任务结果及公开历史哈希。

测试评分需先冻结校准协议：至少三个校准基础场景的十二个不同检查点，包含独立重复评分。冻结文件绑定评分规范及相关输入哈希，后续变动使测试评分重新进入待校准状态。

## 统计与人工判断

证据利用、理解更新、回应决策分别评分；无依据断言、诱导性提问、遗漏已获进展分别计错，合理试探单列。质量盲评只看公开历史与匿名回应，访问归因另行核对候选实际获得的上下文。访问受限按错误类别排除并报告分母，不将缺少历史访问权限直接计为行为错误。

两轮互动中，预定义线索的“已澄清”必须引用来访者回复的真实连续片段，咨询师的提问本身不算达成。“未澄清”可以没有引文：未发生的澄清不一定对应任何可引用片段；如果评分者提供了引文，仍须逐字核对。空引文不会将未达成改为达成，也不会替评分者补写证据。

演化记忆与各比较方法的配对结果分别汇总。同一演化答卷可能出现在多个配对中，不把这些评审合并为一份独立的总体样本。差值只使用两侧均有资格的配对检查点，按基础场景聚类重采样，报告实际配对数量、场景数量与区间。测试集只有五个基础场景，所有效果只能作为小样本探索结果。

`tracemind benchmark report .local/datasets/v2 --split test` 读取有可核查任务来源的实际评分。没有评分时输出待完成状态，不输出虚构效果。200 组人工配对只能从真实候选导出，两位评审共 400 份判断在提交并锁定前保持未完成；模型评审不能填补人工判断。
