# 开发数据修订记录

G001 的 S4 共享开场曾被独立模型审查拒绝：开场未接续当前卡片已建立的每日核对安排，也可能抹去渐变分支已获得的进展。该判断是模型质量审查意见，不等于人工裁决。

根因是旧开场生成器只收到中性场景描述，没有四个分支当前已经发生的共同事件。修订后的 `shared-current-events-v2` 将当前事件的交集提供给开场角色，明确禁止添加新危机、截止日期或将已有应对机制写成尚未建立。角色不会收到其他分支的私有心理状态或未来卡片。已有保留开场继续引用原任务，不会静默改写。

本次修订仅涉及开发集 G001 的 S4–S6。S1–S3 保留。原始全量目录、被拒绝审查、受影响的证据向量及记忆版本均备份到忽略提交的本地归档；对应检查点、标注、答卷与后续记忆缓存从活跃结果中移出，重新生成后须重新审查。API 原始响应和任务账本继续保留。旧结果不计入修订版有效数据规模，也不作为新实验结果。

`scripts/repair_development_group.py` 是此次特定修订工具，不调用 API；拒绝操作非开发集、没有明确拒绝记录的组或已冻结正式评分协议的数据。新生成结果仍可能被审查拒绝，程序不会覆盖拒绝意见或重试直到批准。
