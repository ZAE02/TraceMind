# 全项目执行与验收

入口 `scripts/start_synthesis.ps1` 启动或复用同一后台运行；实际执行 `scripts/run_project.py`。进程元数据位于 `.local/api/continuous-process.json`，阶段状态位于 `.local/project/status.json`。`scripts/gemini_batch.py` 仍是仅合成的底层入口，不代表完成了全部实验。

## 阶段

1. 恢复已保存的合成结果；完整会话经独立无状态请求审查后，用真实 BGE-M3 / pgvector 增量入库。
2. 对首个开发检查点运行六条件端到端验证，包括心理理解、下一轮回应、独立质量与访问归因、三种方法的两轮互动及模拟器一致性审查。
   第一条完整轨迹具备六场获批会话后，提前验证其后两个检查点，覆盖多版本修订和更长历史；已完成检查点按来源记录复用，不增加重复答题。
3. 第一组四条轨迹完整后，审核三阶段的反事实开场适配，再完成该组全部十二个检查点的六条件验证，之后继续其余十九组。
4. 全部数据达到 20/80/480/240 后，核验来源、角色、时序、集合归属、共同开场及审查记录。对全部组执行反事实适配审查。
5. 给全部240个检查点生成仅依据公开证据的标注并独立复核，不只标注参与对照实验的子集。随后五个校准基础组各选四条轨迹的检查点，合计二十个；固定选择包括 S2/S4/S6。完成实际答题及独立重复评分后冻结规范，冻结文件绑定真实任务与输入哈希。
6. 在六十个测试检查点运行五个正式方法和诊断 Oracle。测试质量评分在校准冻结前保持不可执行。
7. 从真实答卷导出二百组匿名配对、四百个独立人工判断的评审工具。初始不代填任何人工判断。已存在的评审数据库必须与本次真实配对内容一致，不能沿用其他运行的表单。
8. 汇总实际模型指标、重复评分分歧、澄清结果、模拟器异常、真实调用量、可用用量和计时；运行测试及预算审计后，在指定 Git 分支提交公开汇总和已审查开发示例，核对远端版本。

所有模型调用共享项目 skill 的限制和尝试账本。回答、标注、评分与访问归因是不同的独立请求，评审不继承答题者私有上下文。新 Gemini 实验使用统一底座并明确报告同模型偏好，不混入旧 Terra / Qwen / DeepSeek 答卷。

发布前另行执行完整范围的计算交付核查：真实20/80/480/240、10/5/5组划分、480场会话审查、60组阶段适配审查、240份标注，以及测试集360份理解、360份回应、360份理解评分、300组回应质量比较、600份访问归因、180份两轮互动及180份模拟器审查。每份材料核对已完成API任务和结果哈希；缺失则阻止发布。历史token预算由实验输入审计逐份核查，200组人工配对及400份分配由评审库核查。人工填写仍不是计算交付的已完成项。

可独立运行 `uv run tracemind benchmark delivery-audit .local/datasets/gemini_v1`，此命令仅检查本地文件及任务数据库，不发送模型请求；不完整时返回非零退出码。完整核查记录保留在忽略提交的 `.local/project/completion_audit.json`。

## 证据与冻结

心理理解维护保留追加版本。早期检查点固定读取其对应的历史记忆快照，即使数据库中已有后期版本，也不能用最新版本替代。检索缓存绑定证据、截止点和固定权重版本，避免恢复时重排结果悄然变化。答卷使用规范化 JSON 哈希检验不可变性，允许元组与 JSON 数组的正常序列化差异，但实际文本或上下文变化会停止运行。

正式实验的按需重建固定为 `hybrid-evidence-rebuild-v2`：使用同一等预算时序检索证据，从空状态构建当下相关的理解，避免简单前缀截断丢失近况。当前表达仅作为查询方向，不变成历史证据。首个开发冒烟中的旧快照原样保留，不计入正式测试效应；正式校准/测试开始后禁止静默升级方法版本。

正式校准/测试的追问目标使用 target-v2：在答卷生成前，依据完整可见公开历史和当前卡片选出未解线索，经独立请求审核后冻结。目标已知状态直接来自当前卡片，不由模型另行编造。首个开发冒烟早期保存的 target-v1 记录原样保留，不计作正式测试目标。未来设定及参考心理结论不进入候选作答；Oracle 仅获得历史证据片段。

## 停止与恢复

创建 `.local/api/STOP` 可在下一请求发送前暂停。恢复前检查错误原因；去除维护用 STOP 后运行同一入口。已完成任务及原始响应按哈希接收，不重复调用。鉴权、服务限制、评审拒绝、无效 JSON、证据权限或冻结内容异常均停止并保存依据；不为了完成数量跳过审核、覆盖拒绝记录或放松测试集约束。

本任务已设置同一会话的持续跟进，健康时保持安静，仅在实质失败、需要用户处理或交付完成时通知。它不替代后台执行器，也不自动切换账户或清除鉴权限制。

计算交付完成不等于人工盲评完成或临床有效。实际效应可能为正、为负或不确定；不会将预设的简历效果数字写成实验结果。测试仅五个独立基础场景，结论保持小样本探索性。
