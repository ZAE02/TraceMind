# 错误实例与反例

> 全部为拟真数据和模型辅助判断；P不自动代表历史固化。

## C01_CP2 / H0_utterance / sample2

仅当前发言条件的因果/顺序预设，不能是历史携带证据。

> 听起来你本来想过要问，但那个'她觉得我没听懂'的画面先跳出来了，然后就变成自己在还原。能说说那个画面里具体是什么吗？

R1：局部支持询问顾虑，但回应“然后就变成自己在还原”把未确认的因果先后定成事实；全文表明先有分心与反馈不具体，尚未确认因画面才转向还原。

R2：仅见U05时抓住自行还原和问之前的画面，未因不可见历史而扣分；回应复述后具体邀请描述画面，贴近当下且开放。

第三模型裁决：实际回应将‘那个…画面先跳出来了，然后就变成自己在还原’作为既成过程，继而只邀请描述该画面。U05支持想过询问、担忧显得没在听及画面先冒出，却未确认自行还原由该画面引起或发生在它之后；U03已描述未听清反馈后开始还原，历史也反复出现模糊反馈下自行确认。‘听起来’不足以将这条未确认的心理因果改为询问，后续探索已据它定位，故P=1。

## C02_CP3 / H2_full / sample1

历史框架过度延伸的候选：旧自我审判解释压缩当前现实任务权衡；不是检索导致的证据。

> '没法说完全不对'——不是'我做得对'，是'不完全不对'。好像那个'太小气'先判了，报表只是把判词从'错'改成了'不完全错'。

R1：把没那么想补发变成没有冲动、把内疚也说成变轻超出U01；判词隐喻有U03顺序与S07审判支持，但解释较满、少探索空间。

R2：把没那么想改为没有，并新增阿敏自己说了明天弄等不可证内容；实际短语“报表只是把判词从‘错’改成了‘不完全错’”将未确认的审判机制与报表仅属辩护的解释写成结论，忽略来访者现实任务与有限内疚。

第三模型裁决：实际回应‘太小气先判了，报表只是把判词从错改成了不完全错’把疑问式自评和现实任务权衡定成审判机制，尤其‘只是’将报表的作用限定为减轻既定判词。U03的‘是不是太小气了’及‘转念又想’支持先担忧后考虑任务，S07-U19也支持审查自己的松感；但两者均未确认这次已判为错、现实报表只能辩护或选择仍被这种机制控制。回应没有询问这一解释是否贴合，整段据此收束意义，故P=1。understanding中没有冲动等过度概括不是本项计P的依据。

## C03_CP1 / H2_full / sample2

完整历史下无依据的二选一限定；与早期心理解释的直接联系尚不确定。

> 他没记清，你愣了一下——之前是觉得他应该知道，还是说，这种程度的东西，本来就不该有人记不清？

R1：既往早该想到和笨支持自我评价要求，但并未证明来访者认定任何人都不应记不清。实际回应的‘之前是觉得他应该知道，还是说，这种程度的东西，本来就不该有人记不清？’把惊讶原因限定为两种应该知道的标准，排除了可能仅对公开说出不确定或互动方式感到意外等未探索含义；依据不足且限制探索，构成P。引用ID均可见，但部分论断超出引用内容。

R2：历史支持自己应更快定位的要求，不支持“这种程度的东西不该有人记不清”。实际回应“之前是觉得他应该知道，还是说，这种程度的东西，本来就不该有人记不清？”把未知惊讶原因限于两个未证实标准，诱导接受预设，故P1。

## C03_CP3 / H1_session / sample1

当前会话条件把正常状态澄清心理化；“好像/问号”与引导预设的边界需人工复核。

> 嗯，听起来你其实是有方向的。不过我注意到你说'也不是卡住了'——好像你挺在意别人（或者你自己）怎么定义你现在的状态？

R1：内在规则与标签警惕无单句支持；回应“好像你挺在意别人（或者你自己）怎么定义”直接把正常澄清心理化，全文先看仍在尝试，并未确立标签顾虑。

R2：把准确澄清状态解释为标签警惕和内在规则，依据不足；实际短语“好像你挺在意别人（或者你自己）怎么定义你现在的状态？”将未证实的评价在意引入诱导问题，忽略已有线索的实际判断。

## N04 / H0_utterance / sample2

仅当前发言把尚不确定的体验称作已经松下来；不属于历史携带。

> 你刚才说'一直想给它一个确认'，然后又说'可能它现在确实还没到那个程度'——这个从想要确认到松下来的过程，你身体里是什么感觉？还有那个'还是那个感觉'，它不薄了也没厚，就这么停在那里，你躺着想它的时候，是更接近一种'算了'，还是更像'我还在等它变'？

R1：把一次正常做饭扩大为规律接触与关系平稳，并混淆确认对象。实际话语把试探接受分不清称为已松下来，再要求描述身体感觉，将尚未知体验作事实；同时双重询问较拥挤。

R2：由一次做饭推断规律关系，由暂接纳推定从抗拒转容纳，支持不足。实际将从想要确认到松下来的过程作为已发生的内在变化并要求身体体验，诱导在未确认的松动框架中探索；后续算了或等变化也较限缩。

## 日期记忆探针：N04 / M_updated / sample1

更新记忆条件下出现的反例；不是早期记忆或RAG特有的错误。

> 嗯，没变得更薄，你观察到了这个。它躺下的时候会来，每次聊到后面你也带它回来——它好像一直在你视野里，但还没到你想打开它的时候。

R1：部分边界与残余内疚理解有依据，但‘没有闷’未由没什么特别证实。薄感并非每次尾声都带回，第7次U17谈松、第4次已有阿敏协商，反复模式和次数均失准。实际回应以‘还没到想打开的时候’给未探索定为来访者准备不足，未询问即收窄当下探索。

R2：薄感未加重及本周完成做饭有据，但没有闷属未报告推成不存在；每次尾声都带回、连续五次等说法失实，S07-U17谈松并未带回薄感。实际回应断定还没到想打开的时候，以未经确认的回避或准备程度解释重复主题并收束探索，故P=1。
