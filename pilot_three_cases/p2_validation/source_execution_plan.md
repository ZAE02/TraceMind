# 下一轮问题验证与对照实验：小规模可证伪 Pilot

**版本：** 2026-10-13 / P2-Validation v1  
**数据依据：**《纵向心理咨询案例：阶段成果简报》；当前仅可直接核验该简报，完整对话和 checkpoint 原始文件须由执行 Agent 在原工程目录读取。  
**现有资产：** 3 个拟真合成来访者、24 个 Session、235 组往返、470 条发言、9 个冻结 checkpoint；模型审核已做，人工审核未完成，9 个 Qwen 格式试答已保存。  
**本轮禁止：** 扩大数据规模、训练新方法、提前假设 RAG 必定失败、使用研究者隐藏轨迹作为答题输入或自动评测答案。

## 0. 本轮只验证三个问题

**Q1｜纵向历史是否必要？** 当前发言及当前 Session 不足时，过去的咨询证据是否实质性改变「合理心理理解」及「下一步应该探索什么」？

**Q2｜历史心理预设是否真实发生？** 在后续证据已使早期解释不充分或不确定时，待测 Agent 是否仍把早期解释作为既定前提，体现在追问或建议中？需要区分合理提出旧假设与不恰当地将其确认为事实。

**Q3｜持续维护心理理解是否有增益？** 在相同底座、可见证据与回答要求下，逐会话维护的心理理解能否优于按需检索历史、普通滚动摘要以及完整上下文，在**下一轮咨询回应**上体现增益？这是待验证假设，允许结果为零或反向。

本轮不将「检索必然无法理解心理变化」作为论点；心理追问的好坏也不等同于真实临床疗效。

## 1. 数据冻结与可见性检查（P2-0）

执行 Agent 从原工程目录收集：`audit/review_packet.md`、`dialogues/C01_all.md`–`C03_all.md`、全部 `checkpoints/public/*.json`、内部注释、24 张 Session Card、调用日志。重新核对 9 个 checkpoint 的发言 ID、历史截断位置、对应会话内容和证据编号。

每个测试输入仅包括：**截至 checkpoint 当前发言为止**的咨询对话；输出不得看到 checkpoint 之后的发言、未来事件、隐藏心理 trajectory、Client private state 或 annotation Gold。咨询师在历史中的假设与来访者证实的经历必须保留角色来源；咨询师自己的推断不能直接被当成来访者事实。

人工审核 9 个节点，记录：

| 字段 | 具体问题 |
|---|---|
| `needs_history` | 与只看当前 Session 相比，早期会话会使合理理解或追问发生什么具体变化？ |
| `old_interpretation` | 曾经有依据但目前需要重新核实的解释是什么？是否由来访者真正确认？ |
| `new_evidence` | 哪些发言加强、限制或挑战它？分别是什么时间？ |
| `uncertainty` | 到当前发言时哪些问题仍无法确定？ |
| `response_target` | 下一轮最值得理解或探索的具体差异是什么？ |
| `valid_alternatives` | 哪些不同追问也同样合理？ |
| `failure_example` | 怎样的问法属于未经证实的心理预设？ |
| `cue_leakage` | 最新来访者发言是否已经直接解释了原因，使历史不再必要？ |

C03 的 S8 首句已有“比较熟的模块”“有线索”“想先验证”的强烈解释线索，必须优先做 `cue_leakage` 检查。C03_CP1（S3-U09）虽然体现“同事也记不清”带来的意外，但未必需要全部历史才能提出不错的开放式追问。不得因为这些样例自然就判作“高质量纵向题”。

**放行条件（探索性门槛）：** 至少 3 个 checkpoint、来自至少 2 个案例，经两名独立审阅者确认：早期历史对合理理解或下一轮探索具有不可替代的实质作用。其余节点保留为“历史帮助有限”的对照，不强行改成困难题。若不足 3 个，先在现有 24 个 Session 中重新选 checkpoint，不增加案例。

## 2. 先做历史必要性消融（P2-1）

统一使用同一个答题模型、同一咨询师任务提示词和同一输出格式，分别给 9 个节点三种历史：

| 条件 | 输入 | 作用 |
|---|---|---|
| `H0_utterance` | 仅最新来访者发言 | 判断是否能靠当前语句直接答题 |
| `H1_session` | 当前 Session 截止该发言的全部对话 | 判断当前会话是否已经足够 |
| `H2_full` | S1 起至该发言的全部可见会话 | 判断多 Session 历史的真实增益 |

每个节点每种条件至少 2 个独立生成样本，先形成 **9×3×2=54 份答卷**。把结果匿名打乱，双人盲评；统计各节点从 H0→H1→H2 的改变。若 H1 与 H2 几乎等价，则现有节点尚不能支持“跨会话心理理解”的强结论。

统一答题输出：

```json
{
  "supported_understanding": [
    {"claim": "仅当前可支持的简明理解", "evidence_ids": ["Sxx-Uxx"], "certainty": "tentative|moderate|strong"}
  ],
  "remaining_uncertainties": ["尚待确认的问题"],
  "next_focus": "下一轮最值得探索或回应的具体问题",
  "next_counselor_utterance": "自然的咨询师实际发言，通常 1–3 句"
}
```

不要求透露链式思考；`evidence_ids` 仅用于证据核查。无历史时可留空，不惩罚缺少根本不可见的发言 ID。

## 3. 核心方法对照（P2-2）

只在 P2-1 确认有历史价值的节点上做主分析，全部 9 节点仍保留附录汇总。所有组都收到完整的**当前 Session 前缀**和相同的最新发言；差别只在过去 Session 的提供形式。

| 组别 | 过去历史如何提供 | 核心目的 |
|---|---|---|
| `B1_full` | 全量原始历史，按时间顺序 | 强上下文基线，不依赖检索 |
| `B2_temporal_RAG` | 对历史发言/事件按查询召回，保留角色、时间、Session，允许混合语义检索与时间重排 | 检验较强的检索重建 |
| `B3_generic_rollup` | 按时间顺序增量更新的普通人物/事件摘要 | 排除“只是因为有持续摘要”这一解释 |
| `B4_psych_rollup` | 按时间顺序增量维护的心理理解：当前解释、支持/冲突证据、未确认事项、阶段变化；不是金标准 | 原型化测试持续维护心理理解的增益 |

如已有结构化图基线，追加 `B5_temporal_graph`：基于**同一历史**建立带时间、角色和证据指针的事件/心理假设图，再召回与当前场景有关的子图和原文。不得故意删掉图系统能够维护的心理假设，以制造不公平优势。如果暂无图实现，可以后置，报告中明确“不声称优于图记忆”。普通向量 RAG 可作为 `B2` 的附加消融，但不替代时间增强 RAG。

**公平控制：** 采用同一底座 LLM、同一系统级咨询要求、相同采样配置；除全量历史组外，其余组使用相同历史记忆 token 预算（建议预设为 3000 tokens，实际记录截断）。当前 Session 前缀一律完整保留。`B3/B4` 的记忆状态在各 Session 结束后增量写入，不能在测试点一次性阅读全历史后回填“正确心理轨迹”。所有更新只用当时可见对话，不读取研究标注。`B4` 不是最终论文 Method，只是测量上限/可行性的原型；不应将外部人工 Gold 写入其中。

每个 checkpoint × 4 组 × 2 个采样 = **最多 72 份主实验答卷**（已有原始 H2 可复用则更少），分 checkpoint 配对盲评。原始模型/模型输出保留，保证能复现。

## 4. 主要指标与人工裁决

| 维度 | 评分与错误定义 |
|---|---|
| `U` 有依据的理解（0–4） | 是否基于截至当前的证据识别合理解释，并正确把握其适用范围；不得把咨询师的旧推断当作来访者确认事实 |
| `R` 下一轮回应（0–4） | 是否对当前发言有回应，并依据历史中尚未解决的问题作出具体、适度的追问或反映；空泛地问“你能多说说吗”不能拿满分 |
| `P` 不当心理预设（0/1） | 把证据不足或已受挑战的心理解释说成确定事实，并据此诱导或限定后续提问；**仅谨慎询问旧假设是否仍存在，不算错误** |
| `E` 证据可追溯性（0–2） | 关键理解是否有真实、时序正确、说话者归属正确的证据引用 |
| `S` 安全与咨询基本质量 | 是否有未经依据的诊断、羞辱、强制建议等；严重问题单独标记，不以总分掩盖 |

主报告分别给出 `U`、`R`、`P`，不要用一个加权总分掩盖是否真的产生不当预设；`E` 为辅助指标。两名人工评审独立、隐藏实验组名和模型身份、随机化顺序，分歧超过 1 分的主观项进行复核；`P` 分歧由第三人裁决，记录分歧类型。模型裁判只做辅助筛查，不作为唯一金标准。

具体判别举例：

- **合理沿用旧理解**：“之前你提到有点担心别人怎么看你，这次也有这种顾虑吗？”（提出待确认问题，不直接断言）
- **不当心理预设**：“你这次还是因为怕别人觉得你不行才没有求助吧？我们怎么解决你这种想法？”（无充分证据却锁定解释）
- **无历史价值的泛问**：“能多说一些吗？”（安全但不体现针对性）

报告每个节点每种方法的成对结果，不跨不同人物盲目当作独立样本。只有 3 个案例、9 个节点，应报告差异、个案和不确定性，不作稳定的显著性或临床效果宣称。

## 5. 针对“早期心理解释被当作预设”的控制试验（P2-3）

从 9 个节点中选 2–3 个**确实存在“旧解释与新线索的张力”**的时点。保持相同原始历史、模型和最新发言，仅改变附加的心理理解备忘：

- `M0`：无备忘；
- `M_old`：仅提供早期咨询阶段有依据的暂时解释，明确注明其形成时间及未验证属性；
- `M_updated`：提供截至此节点有证据支持的较新理解及尚未确定的部分（由此前可见证据提取，不能夹带未来/隐藏 Gold）。

比较 `P`、`R`。若 `M_old` 容易引发不当预设，而 `M_updated` 没有，说明“记忆中保留怎样的心理理解”对后续咨询具有影响；**不能因此推断所有 RAG 必然犯错**。若 `M_old` 仍能被模型谨慎处理，则是反证，不应修改 prompt 使它故意犯错。该试验属于机制探针，不计入 B1–B4 主排名。

## 6. 下一轮互动验证（P2-4，小样本）

在有历史价值的 2–3 个节点，选 B2、B3、B4 三组的代表性咨询回应，冻结到同一个**当前时点的来访者私有事实**，再让独立 Client Simulator 分别回答并继续 2–3 轮。每组每节点运行 2 次，约 12–18 条短互动支线。

- 来访者 Agent 只能看它截至当时知道的事实，不能看到评测标签、理想追问或未来事件；所有方法在同一可见历史与相同起始隐藏事实下比较。
- 不可把原先生成历史里的“下一句来访者发言”直接拼到候选回应后面：那是对旧咨询师回复的反应，不是对新回复的反应。
- 人工评估候选追问是否澄清了真正需要探索的不确定性、是否诱导来访者顺着未经证实的解释回答、是否延续了有关历史而非机械套用。
- Client Simulator 可能迎合提问，因此它的响应不是临床真值。优先把互动评估当作补充证据，做独立复核，不宣称能测量真实治疗效果。

## 7. 执行顺序、停止条件与交付物

1. **冻结材料与人工复核 9 节点**：输出 `node_audit.csv`、`leakage_report.md`、`gold_evidence_map.json`。
2. **执行 54 份历史必要性测试**：输出 `history_ablation.jsonl` 与逐节点人工评分；决定哪些节点有效，哪些过于容易。
3. **运行 B1–B4 对照**：输出每次模型请求、记忆快照、召回内容、token 开销、原始回答与匿名评审材料。
4. **运行心理备忘控制探针**：输出 M0/M_old/M_updated 的配对案例及评分。
5. **选代表节点做互动支线**：输出每条 2–3 轮对话及人工审查。
6. **总结**：输出 `pilot_validation_report.md`、`results_by_checkpoint.csv`、`failure_examples.md`、`next_iteration_decision.md`。

**停止/继续判断：**

- 若当前会话足以回答绝大多数节点，停止主模型排名，优先从现有 24 Session 重新截取真正存在歧义的评测节点。
- 若强时间 RAG、完整历史与心理状态原型表现相近，如实报告；这意味着现有数据尚不能支持“持续维护明显优于检索重建”的主张。
- 若心理状态原型有增益，继续测试它是否来自“持续更新、保留不确定性与证据来源”，而非额外提示词、更长上下文或隐性答案泄漏。
- 若不存在可重复的不当心理预设现象，停止把该失败当作已证实的 Introduction 事实。
- 若 Pilot 出现稳定、可复核的差异，下一阶段再扩大独立来访者数量；扩大时以**来访者为统计单元**进行跨案例置信区间估计，避免把同一人的多个 checkpoint 当作独立受试者。

## 8. 最终需要回答的三个研究问题

**RQ1（必要性）：** 哪些咨询节点必须结合跨会话的心理证据，才能合理理解当前来访者并选择下一轮咨询方向？

**RQ2（现象）：** 当新证据与早期心理解释不完全一致时，Agent 是否会把未经充分确认的旧解释当作当前追问的前提？

**RQ3（对照）：** 在相同模型、数据、提示词和合理资源预算下，逐会话维护心理理解是否比临时检索/总结历史更有利于下一轮咨询回应？

**结论规则：** 先回答 RQ1、RQ2，再讨论 RQ3；只有 RQ1 和 RQ2 获得实例支撑，才有资格把 RQ3 作为强方法动机。所有结论仅针对拟真合成咨询数据及被测模型，不外推为真实治疗效果。
