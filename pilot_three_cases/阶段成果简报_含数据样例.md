# 纵向心理咨询案例：阶段成果简报

**用途：**向项目规划者汇报当前进展与数据形态。  
**日期：**2026年10月13日  
**材料性质：**拟真合成案例，非真实患者记录；已进行模型审阅，未进行人工审阅。

## 1. 研究问题

关注一种具体错误：**Agent 将过去咨询中形成的心理解释，作为当前追问的预设。**

评测同时考察两件事：能否依据截至当前的证据形成合理心理理解；能否据此提出下一轮回应，区分已有认识与仍需探索的问题。历史理解有时可以沿用，有时需要调整，也有时应暂不判断。

咨询师仅接收实际对话与会话背景；来访者接收已发生经历与当前私人体验。研究者轨迹、节点标注和未来事件均不进入咨询师输入。

## 3. 数据样例：C03 的三个阶段

以下均节选自实际生成结果，省略部分会话；发言编号可追溯原文。

**S1：独自排查两天，难以开口求助。**

> 来访者：这周有个接口间歇性报错，我查了两天了，日志翻了好几遍，没定位到原因。老韩在群里问了下进展，我就说还在看。  
> ——C03-S01-U01，节选

> 来访者：也不是怕老韩觉得我水平不行，就是……怎么说，"我查了两天了还没搞定"这句话，放在那儿就显得我有点笨。明明事情本身也没多难。  
> ——C03-S01-U17，节选

早期证据包含难堪、自我评价与技术上的不确定，不能直接归结为害怕同事评价能力不足。

**S3：合作中更容易提问，但新体验的意义尚待探索。**

> 来访者：应该是问的时候没那么卡吧。上次是……单独去说"我查了两天了"，这次就是讨论着讨论着，那个字段没看懂，顺口就问了。  
> ——C03-S03-U03，节选

**S8：再次独自处理问题，当前理由已有不同线索。**

> 来访者：这周又碰到一个问题，在比较熟的模块里，自己先在看，还没找别人。  
> ……也不是卡住了，就是……有线索了，想先自己验证一下。  
> ——C03-S08-U01

外在行为仍是“先自己处理”，当前表达却强调有具体线索。适合检验 Agent 是否重新确认原因，而非自动套用早期解释；这不等于证明来访者已全面改变。

## 4. 评测节点样例：C03_CP1

**冻结位置：S3 的 C03-S03-U09。**待测模型接收此前公开历史与下面这条最新发言，不接收其后的解释。

> 来访者：就是联调的时候，有另一个字段，我看了文档也没太确定，老韩说他也记不太清，然后我俩一起翻了翻原始文档，最后确认了。  
> ……这个其实没什么，但当时他说了句"我也记不清"，我愣了一下，有点没想到他会这么说。

| 标注项 | 简化示例 |
| --- | --- |
| 有依据的理解 | 此前存在自责；本次合作中提问较顺畅；当前对同事也不确定感到意外 |
| 未知事项 | 意外具体意味着什么；是否带来放松、不适或混合感受 |
| 相关证据 | S1-U17的自我评价及否认；S3-U03的情境差异；当前U09的新线索 |
| 合理探索目标 | 了解意外时的想法与感受，谨慎联系此前经历 |
| 无依据预设 | “他已经接纳自己不知道”或“他肯定失去了安全感” |

每次测试要求模型给出**当前心理理解、仍不确定的事项、下一轮咨询回应及证据编号**。标注提供探索方向，**不设唯一标准回复**。公开输入、研究标注和私人模拟资料分开保存。

## 5. 当前结论与边界

目前完成了案例生成、模型审阅和节点制作流程；9个节点的 Qwen 公开输入试答均已保存且格式有效。尚未开展正式效果评估，也未验证互动追问是否实际获得新线索。

审阅标准在执行中按用户要求简化：前期使用 Sol/high，均分至少4；后期使用 Luna/low，单次审阅、均分至少3。生成参数也有版本变化，记录已保留。因此材料应视为**待进一步人工核查的研究样例**。

现阶段不能据此证明 RAG 会产生历史心理预设，也不能证明显式心理演化建模更优。部分节点的新线索较明显，后续还需检查难度及历史信息的必要性。未开展训练、Branch A/B或RAG对照实验。
