## 结构审计与调用用量

`audit.json` 显示结构审计完成、无已检出的结构问题：64 次会话均有 16 条交替发言；24 份标注的证据 ID 均在冻结前公开输入中；C0 无历史，C3 对应完整既往会话，C1/C2 的引用 ID 来自既往会话；192 份答卷的输入哈希与落盘输入一致。扫描本目录可读文本文件，未发现所提供的完整密钥。

调用日志记录共 **7,368,098 输入 token**、**776,835 输出 token**（含不完整响应、重试和检索探测），这是接口回报用量的汇总，不能直接当作人民币账单。主要构成为：会话生成 1,047 次成功响应，其中 1,024 条发言落盘、23 次输出不完整；标注 64 次成功响应，其中 24 份草稿落盘、40 次输出不完整；答题 192 次成功响应。曾有 1 次答题被服务端内容检查拒绝，同一输入与参数重试后完成。网络代理短暂拒绝连接的失败尝试也保留在日志中。

批量 Embeddings 接口在本次运行中对同批向量均返回 `index=0`。检索实现已改为按响应顺序映射，并启用 `retrieval/cache_v2/`；此前试验产生的 `retrieval/cache/` 不参与最终检索。C1/C2 的实际排名和所选片段见 `retrieval/P*_CP*.json`，最终输入见 `inputs/`。
